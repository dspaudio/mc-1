Install MC-1 firmware

Update your M-VAVE FM-1 over its USB MIDI connection. The emulator and the physical instrument are separate.

1. Verified release

1.1.0 dual-core is the default: eight melodic voices, six drum voices, four FX banks and optional Analog variance. Choose the immutable original 1.0.2 single-core release as a fallback.

2. Connect your instrument

Connect the FM-1 directly by USB and stop playback. Close other MIDI applications, including the emulator's MIDI connection.

The connection step automatically finds the FM-1 and reads its identity. It does not send firmware data.

3. Install and verify

Keep USB and power connected until the instrument has restarted and verification is complete.

1.1.0 saves projects in format 8. 1.0.2 cannot load format 8. Switching firmware is not project conversion or a backup; saving after a downgrade can overwrite prior project banks. Preserve your projects before switching versions.

Verify a release and connect an instrument to continue.

This page needs Web MIDI with SysEx permission, available in supported desktop browsers such as Chrome and Edge. If it is unavailable, use the desktop installer linked in the release.

Restore official V15

To return to M-VAVE firmware, download the official FM-1 V15 package from M-VAVE downloads and select its unmodified FM-1.fwsc file.

The official V15 application image is preserved. This page uses the verified MC-1 release's small update loader, not the official package's large loader. It does not rewrite the separate factory USR patch bank or perform a factory reset.

Select the official V15 file after the MC-1 release is verified.

Connect your instrument above before restoring. Keep USB and power connected until restart verification completes. If interrupted in the update loader, reconnect and retry the same restore.

Crashes, restart and recovery

A catchable CPU1 timeout or worker protocol failure disables the worker and recomputes the failed work on CPU0. Single-core fallback is not guaranteed to sustain full-load real-time audio.

A fatal system fault stops audio and attempts UBOOT only when CPU1 is held safely. A power cycle retries the same installed image, not an automatic rollback. Startup faults can persist after restarting.

If the MIDI update loader is still available, reconnect and retry the same selected package. ROM WL80UBOOT is not the Web MIDI update loader: this page cannot recover a device in that state. Expert app-only recovery is required; do not treat the web installer or V15 restore as ROM recovery.
